# 📚 BookNest – Library Management System

BookNest is a Library Management System developed using Python Flask, SQLite, HTML, CSS and Streamlit. It helps manage books, students and borrowing activities efficiently.

## 🚀 Features

- Add new books
- Edit and delete book details
- Search books by title, author or category
- Register students
- Issue books to students
- Return issued books
- Track book availability
- View library statistics
- Interactive analytics dashboard

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Streamlit
- Pandas
